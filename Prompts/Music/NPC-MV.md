# NPC — MV Shotlist

> [!abstract] สรุป
> ดีไซน์ตัวละคร + shotlist เอ็มวีของเพลง [[NPC]] — หญิง = **NPC** ที่ติดลูปในเกม / ชาย = **Player** หน้าตายที่มาสแปมปุ่มคุย
> สไตล์: คัตติ้งไวๆ weird อาร์ตๆ ใช้ภาษา UI เกมเป็นลูกเล่นหลัก ตัดบนบีต (128 BPM)

---

## A. ดีไซน์ตัวละคร

### 🎀 THE NPC (Female)
**คอนเซ็ปต์:** เด็กสาว kawaii-toxic ที่ติดอยู่ใน loop ของเกม รู้ตัวว่าเป็นตัวประกอบ แต่แสบและไม่แคร์

- **หน้าตา/ทรง:** สาววัยรุ่น ตาโต แต่มี dead-eye แวบๆ เหมือนตุ๊กตา, ผมสี **cyber-pink → cyan** ไล่เฉด, ทรงบ๊อบสั้นเป๊ะเหมือนตัดจากโมเดล 3D
- **เสื้อผ้า:** ชุดกระโปรงพาสเทลนีออน + choker มี LED, มี **ป้ายชื่อลอยหัว "NPC"** สีเทา (ไม่มีชื่อจริง), health bar เต็มตลอด
- **ซิกเนเจอร์:** กล่องข้อความ `[ ... ]` ลอยเหนือหัว, ยืน idle animation โยกซ้าย-ขวาเป็นลูป, ยิ้มค้างเหมือน freeze frame
- **พาเลตต์:** hot pink / cyan / white bloom / ดำสนิทพื้นหลัง
- **texture ลับ:** เวลาโดนแตะจะ **glitch/datamosh** แล้ว reset ท่ากลับมายิ้มเหมือนเดิม

### 🎮 THE PLAYER (Male)
**คอนเซ็ปต์:** ผู้เล่นหน้าตาย เบื่อโลก มาสแปมปุ่มคุยกับ NPC ซ้ำๆ อย่างไร้อารมณ์

- **หน้าตา/ทรง:** ผู้ชายผอมสูง เสียง tenor, ผมสีเทาหม่น, **ตาสะท้อนแสงจอสีฟ้า** (blue UI glow บนหน้า), สีหน้าเรียบเฉยตลอด
- **เสื้อผ้า:** ฮู้ดดี้เทา-ดำ oversized, มือถือ **controller เรืองแสง**, มี cursor/reticle ลอยตรงที่เขามอง
- **ซิกเนเจอร์:** กดปุ่ม interact ซ้ำๆ (นิ้วรัวๆ), มีปุ่ม prompt `[A] Talk` โผล่หน้าเขา, เขาอยู่ "นอกจอ" — เฟรมเป็นเลเยอร์ UI ของเขา
- **พาเลตต์:** เทาหม่น / ฟ้าจอ / ตัดกับสีสดของ NPC เต็มๆ
- **ความ weird:** เราไม่เคยเห็นเขาเต็มตัวชัดๆ เห็นแค่มือ, เงา, ตาสะท้อนจอ — เขาคือ "ผู้เล่น" ที่อยู่คนละมิติ

> **Contrast หลัก:** NPC = สีสด/นีออน/2D-flat/ลูป | Player = หม่น/มืด/มือกับเงา/real → ตัดสลับกันเป็นจังหวะ

## B. Shotlist (map ตามโครงเพลง, ตัดบนบีต)

### SECTION 1 — SHOT-BY-SHOT EFFECTS TIMELINE

```
SHOT 1 (INTRO "N-P... N-P...") — Boot Up
• EFFECT: CRT power-on flash + pixel dissolve + chromatic aberration
• จอดำ → เส้น scanline วิ่ง → NPC โผล่มายืน idle กลางเฟรมพร้อม bloom ขาว
• กล้องนิ่งสนิท, กล่อง [ ... ] กระพริบเหนือหัว
• ตัดเข้าจังหวะ "beep!" ด้วย pixel-dissolve เร็ว

SHOT 2 (INTRO "N-P-fuckin'-C!") — Title Card Glitch
• EFFECT: datamosh smear + text glitch + hard zoom pump
• ตัวหนังสือ "N-P-C" เด้งเต็มจอแบบ 8-bit สั่น, สีแตก RGB
• zoom กระแทกเข้า-ออกเร็วบนคำว่า fuckin'
• นี่คือ TITLE HIT — ตัดดำ 1 เฟรมเข้า verse

SHOT 3 (VERSE 1 "Hi!" / "that's your whole script") — The Loop
• EFFECT: freeze-frame stutter + UI dialogue box
• NPC พูด "Hi!" แล้ว freeze, rewind กลับมาพูด "Hi!" ซ้ำ 3 ครั้งแบบ jump-cut
• ปุ่ม [A] Talk เด้งหน้าเธอทุกครั้งที่ Player กด (เห็นแค่มือชายในเงา)
• กล้อง whip-pan สั้นๆ สลับ NPC ↔ ตาชายสะท้อนจอ

SHOT 4 (VERSE 1 "Right. Right. Right.") — Deadpan Cut Triplet
• EFFECT: 3-frame hard cut (จับ 3 คำ = 3 คัต)
• คัต 1: ตาชาย / คัต 2: นิ้วกดปุ่ม / คัต 3: NPC ยิ้มค้าง
• ทุกคัตกระแทกบนคำว่า "Right"
• จบด้วย screen-shake เข้า pre-chorus

SHOT 5 (PRE-CHORUS "Three. Two. One—") — Countdown Charge
• EFFECT: speed ramp (build) + light streak + snare-roll shake
• ตัวเลข 3-2-1 ลอยเต็มจอแบบ HUD, กล้องพุ่งเข้า NPC ช้าๆ แล้วเร่ง
• จอเริ่มสั่นตาม snare roll, สีอิ่มขึ้นเรื่อยๆ
• "One—" ตัดขาดดำสนิท 2 เฟรม → ระเบิดเข้า chorus

SHOT 6 (CHORUS "N-P-fuckin'-C!") — Chant Explosion ⭐
• EFFECT: strobe cut + mirror kaleidoscope + supersaw bloom
• ทุกครั้งที่ร้องวลีหลัก = NPC โคลนตัวเองสะท้อนกระจกหลายตัว (kaleidoscope)
• "beep!" = แฟลชขาวเต็มจอ 1 เฟรม
• tag ชาย (checks out / next / yep) = คัตแทรกตาชาย/นิ้ว 1 เฟรมในช่องว่าง
• >>> นี่คือ SIGNATURE VISUAL — คัตรัวบนทุกพยางค์

SHOT 7 (POST-CHORUS "en-pee-en-pee-C!") — Datamosh Break
• EFFECT: full datamosh + chopped vocal glitch + RGB split
• ภาพ NPC ละลายเป็น pixel เต้นตามเสียง chopped
• "beep beep beep" = 3 แฟลชสี pink/cyan/white
• เละๆ อาร์ตๆ 8 บาร์ ไม่มีหน้าชัด

SHOT 8 (VERSE 2 "Poke you once...") — Interaction Spam
• EFFECT: split-screen + freeze stutter
• จอผ่าครึ่ง: ซ้าย=นิ้วชายกดรัว / ขวา=NPC ไม่ขยับ (idle loop)
• "Locked. Locked. Locked." = ภาพ NPC ค้างแข็งแบบ error 3 ครั้ง
• กล้องนิ่ง เย็นชา ตัดเข้า pre-chorus เดิม

SHOT 9 (BRIDGE "Aren't you bored?") — The Fourth Wall ⭐
• EFFECT: rack focus + slow push-in + desaturate → single spotlight
• half-time: NPC หันมามองกล้อง(=มองผู้เล่น)ตรงๆ ครั้งแรก, สีจางลงเหลือ toy-piano มืดๆ
• push-in ช้าๆ เข้าตาเธอ, พื้นหลังเบลอ
• "(giggle) nope." = เธอยิ้มมุมปาก + glitch แวบ → นี่คือโมเมนต์ human สุดในเพลง

SHOT 10 (FINAL CHORUS — gang chant, semitone up) — Full Overload ⭐
• EFFECT: everything stacked — strobe + kaleidoscope + clone army + zoom pump + shake
• NPC หลายสิบตัวเต้น chant พร้อมกันแบบ stadium
• สีขึ้นครึ่งเสียง = grade สว่างจัด, ทุกอย่างเร็วขึ้น
• คัตถี่สุดในเพลง, blip ทุกช่อง, tag ชายแทรกทุกจังหวะ

SHOT 11 (OUTRO "no name... no script...") — Power Down
• EFFECT: reverse pixel-dissolve + scanline collapse + fade to black
• NPC ค่อยๆ สลายเป็น pixel, ป้าย NPC กระพริบดับ
• "N-P—(cut)" = ภาพถูกตัดกลางคำแบบ hard black + จอปิด CRT (จุดขาวยุบกลางจอ)
• จบแบบ power-off เกม
```

### SECTION 2 — MASTER EFFECTS INVENTORY

```
1. STROBE / HARD CUT ON BEAT (ใช้เยอะสุด) — Shots 2,4,6,10 — ตัดบนทุกพยางค์วลีหลัก คือหัวใจของ MV
2. KALEIDOSCOPE / MIRROR CLONE (3x) — Shots 6,10 — โคลน NPC สะท้อนกระจก = ท่าซิกเนเจอร์
3. DATAMOSH / PIXEL DISSOLVE (4x) — Shots 1,2,7,11 — เข้า/ออก NPC แบบละลาย digital
4. UI OVERLAY (dialogue box / [A] Talk / health bar / countdown) — Shots 1,3,5,8 — เล่าเรื่อง "เกม" โดยไม่ต้องพูด
5. FREEZE-FRAME STUTTER (3x) — Shots 3,4,8 — NPC ค้าง/ลูป = ตอกย้ำความเป็นตัวประกอบ
6. CHROMATIC ABERRATION / RGB SPLIT (4x) — Shots 1,2,7 — ขอบสีแตก อาร์ตๆ toxic
7. WHITE BLOOM FLASH (บน "beep!") — Shots 6,7,10 — แฟลช 1 เฟรมกันเสียง/ภาพลาก
8. ZOOM PUMP (3x) — Shots 2,5,10 — กระแทก scale เข้า-ออก
9. RACK FOCUS + PUSH-IN (1x) — Shot 9 — ช้า สะอาด ใช้ครั้งเดียวในบริดจ์เพื่อ contrast
10. SPLIT-SCREEN (1x) — Shot 8 — เทียบ Player รัว vs NPC นิ่ง
11. CRT POWER ON/OFF (2x) — Shots 1,11 — เปิด/ปิดเป็นกรอบเล่าเรื่องหัว-ท้าย
```

### SECTION 3 — EFFECTS DENSITY MAP

```
INTRO (Shots 1-2)        = HIGH — CRT, dissolve, glitch, zoom pump, title hit (5 fx)
VERSE 1 (Shots 3-4)      = MEDIUM — freeze stutter, UI box, triplet cut (3 fx)
PRE-CHORUS (Shot 5)      = BUILD — speed ramp, HUD countdown, shake (3 fx ไต่ขึ้น)
CHORUS (Shot 6)          = MAX — strobe, kaleidoscope, bloom, tag-cut (5+ fx) ⭐
POST-CHORUS (Shot 7)     = HIGH-WEIRD — datamosh, RGB split, chopped glitch (3 fx เละ)
VERSE 2 (Shot 8)         = MEDIUM-COLD — split-screen, freeze error (2 fx เย็นชา)
BRIDGE (Shot 9)          = LOW ⭐ — rack focus, push-in เดี่ยว (1 fx) จุดพักที่ contrast แรงสุด
FINAL CHORUS (Shot 10)   = OVERLOAD — ทุก fx ซ้อน (6+ fx) จุดพีคของเพลง ⭐
OUTRO (Shot 11)          = LOW → OFF — reverse dissolve, CRT power down (2 fx)
```

### SECTION 4 — ENERGY ARC

- **Act 1 (Intro–Verse 1):** *Boot up.* เปิดเกม → title glitch กระแทก → เผยลูป "Hi!" ของ NPC กับมือ Player ที่มาสแปม สร้างกฎของโลก: เธอติดลูป เขาหน้าตาย
- **Act 2 (Pre→Chorus→Post→Verse2):** *The loop tightens.* Chorus ระเบิด kaleidoscope + ตัดรัวบนทุกพยางค์ (พีคย่อย) → post-chorus ละลายเป็น datamosh อาร์ตๆ → verse 2 เย็นลง เทียบชัดว่า Player รัวแค่ไหน NPC ก็ไม่ขยับ
- **Act 3 (Bridge→Final→Outro):** *Break & overload.* บริดจ์คือ **จุดพลิก** — NPC หันมองกล้อง ทำลายกำแพงที่ 4 เงียบๆ ช้าๆ (contrast สูงสุด) → แล้วระเบิดเข้า Final Chorus overload เสียงหมู่ + ครึ่งเสียงสูงขึ้น → ปิดด้วย power-down ตัดกลางคำ "(cut)" จอดับ = จบเกม
