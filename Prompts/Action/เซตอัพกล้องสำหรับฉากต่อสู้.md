# เซตอัพกล้องสำหรับฉากต่อสู้

> [!abstract] สรุป
> บล็อกสั้นสำหรับ**เซตกล้อง**ในฉากต่อสู้ — handheld ความเร็วสูง สั่น ตัดหลายมุมเร็ว แทรก POV บุคคลที่หนึ่ง สโลว์มาโครตลอด เอาไปแปะหัว prompt ไหนก็ได้

> [!tip] ประเภท
> เป็น **snippet** ไม่ใช่ prompt เต็ม — ใช้ต่อกับบล็อกอื่น เช่น [[Dark Blink Combat]]

## Full prompt

```
【Cinematography Setup】
Handheld high-speed action cinematography, intense camera shake, rapid multi-angle cuts, interwoven first-person traversal perspective, ultra-macro slow motion throughout. Realistic style, 4K cinematic quality, anamorphic widescreen.
```

## แยกทีละส่วน

| คำสั่ง | ได้อะไร |
|---|---|
| `Handheld high-speed action cinematography` | กล้องมือถือ ตามแอคชั่นเร็ว |
| `intense camera shake` | สั่นแรง |
| `rapid multi-angle cuts` | ตัดสลับหลายมุมถี่ |
| `interwoven first-person traversal perspective` | แทรกมุมมองบุคคลที่ 1 ตอนเคลื่อนที่ |
| `ultra-macro slow motion throughout` | สโลว์มาโครตลอดทั้งคลิป |
| `Realistic style, 4K cinematic` | โทนสมจริง คุณภาพระดับหนัง |
| `anamorphic widescreen` | ภาพกว้างแบบอนามอร์ฟิก |

## ⚠️ ข้อควรระวัง

บล็อกนี้**ขัดกับบทเรียนในหมวด Action** อยู่สองข้อ ถ้าเอาไปใช้ตรงๆ อาจได้ภาพที่ดูไม่รู้เรื่อง:

- **`intense camera shake` + `rapid multi-angle cuts`** — กล้องสั่นแรงบวกตัดถี่ ทำให้อ่านคิวบู๊ไม่ออก ถ้าอยากให้เห็นว่าใครทำอะไร ลองลดเป็น `controlled handheld micro-shake` แทน
- **`ultra-macro slow motion throughout`** — คำว่า *throughout* แปลว่าสโลว์ทั้งคลิป ทำให้ไม่มีคอนทราสต์ระหว่างเร็ว-ช้า แนะนำระบุเป็นจุดๆ เช่น "สโลว์เฉพาะตอนดาบปะทะ กับตอนหลบเฉียด" แล้วที่เหลือความเร็วปกติ

> ถ้าอยากได้ความรู้สึกเร็วแบบอ่านออก ให้**กล้องช้า ตัวละครเร็ว** — ดูบทเรียนเต็มในหน้า [[Action]]
