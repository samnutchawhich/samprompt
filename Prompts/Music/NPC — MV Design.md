# NPC — Character & MV Design

> [!abstract] แกนความคิด
> **เธอคือสกินเริ่มต้นที่ยังไม่ถูกแต่ง** — ทุกลุคคือการไล่ระดับจาก "ไม่มีตัวตน" ไปสู่ "มีตัวตน"
>
> เพลงพูดถึงคนที่พูดได้แค่ตามบทที่มีคนเขียนให้ ([[NPC]]) MV จะเล่าเรื่องเดียวกันด้วย **พื้นผิวภาพ** ไม่ใช่ด้วยพล็อต

## 🎯 วิทยานิพนธ์ทางภาพ (สำคัญสุด — ทุกช็อตต้องรับข้อนี้)

| | **NPC (หญิง)** | **PLAYER (ชาย)** |
|---|---|---|
| เฟรมเรต | **กระตุก** — animate on 3s เหมือนขยับทีละสเต็ป | **ลื่น** — 24fps มี motion blur |
| สี | จืด ซีด แบนราบ ไม่มีเงาลึก | อิ่ม มีคอนทราสต์ มีเงา |
| พื้นผิว | เนียนเกินจริง ไม่มีรูขุมขน | เห็นรูขุมขน เหงื่อ ขนอ่อน |
| แสง | แบน ไม่มีทิศทาง เหมือนไฟสตูดิโอ | มีทิศทางชัด มีไฟข้าง |
| กล้อง | **ล็อคนิ่ง** ไม่ขยับตาม | handheld ขยับตาม |
| เสียงเดิน | ไม่มี | มี |

**ความต่างนี้คือทั้งเรื่อง** — คนดูจะรู้สึกว่าเธอ "ไม่จริง" ก่อนที่จะเข้าใจว่าทำไม แล้วตอนจบพอเธอกลายเป็นลื่นและมีพื้นผิว มันจะสะเทือนโดยไม่ต้องอธิบาย

# 👤 ตัวละคร 1 — NPC (หญิง)

## Face lock (ตายตัวทุกลุค)

หญิงเอเชียตะวันออก ปลาย 20 · ผมดำตรงยาวประบ่า มีเลเยอร์นุ่มตกลงมาด้านหน้า · **หน้าสด ไม่แต่ง เห็นพื้นผิวผิวจริง** · ตาสีน้ำตาลเข้ม · **สีหน้าเรียบ ไม่มีอารมณ์** · ริมฝีปากสีธรรมชาติ · โครงหน้ากลมนุ่ม ไม่คม

> ใช้รูป reference ของ Sam เป็น `<<<image_1>>>` — **ห้ามแต่งหน้าเพิ่ม ห้ามทำผิวเนียนแบบรีทัช** ในลุค 1–2 ความสดคือตัวละคร

## Costume Sheet — 5 ลุค

### ลุค 1 · DEFAULT (สกินเริ่มต้น)
| | |
|---|---|
| ชุด | เสื้อไหมพรมคอกลมสีครีมออตมีล ทรงหลวม ไม่มีลาย · กางเกงผ้าสีเทาอ่อน · รองเท้าผ้าสีขาวหมอง |
| ของประกอบ | **ป้ายชื่อเปล่า** ห้อยที่อก — ไม่มีตัวอักษร |
| สี | ครีม/เทา/เบจ — ไม่มีสีสดเลย |
| หมายเหตุ | ตรงกับรูป reference เป๊ะ นี่คือลุคหลักที่ใช้เยอะสุด |
| ใช้ที่ | Intro, Verse 1, Chorus 1 |

### ลุค 2 · GLITCH (ระบบเริ่มรั่ว)
| | |
|---|---|
| ชุด | ชุดเดิมลุค 1 **ไม่เปลี่ยนเลย** |
| เอฟเฟกต์ | สีแยกชั้น RGB เหลื่อมออกจากตัว · ขอบร่างแตกเป็นพิกเซล · ผมบางเส้นค้างในอากาศไม่ตกตามแรงโน้มถ่วง |
| หมายเหตุ | **ห้ามเปลี่ยนชุด** — พลังของลุคนี้อยู่ที่ "คนเดิม แต่มีอะไรผิดปกติ" |
| ใช้ที่ | Post-Chorus, ท้าย Verse 2 |

### ลุค 3 · SHOPKEEPER (บทที่ถูกเขียนให้)
| | |
|---|---|
| ชุด | ผ้ากันเปื้อนผ้าใบสีน้ำตาลทับชุดลุค 1 · ปลอกแขนสีเทา |
| ของประกอบ | ป้ายชื่อยังเปล่า · ป้ายไฟนีออน **OPEN** เหนือหัว (สีส้มอมชมพู) · เคาน์เตอร์ไม้ที่ไม่มีของขาย |
| หมายเหตุ | เธอยืนหลังเคาน์เตอร์ **ที่ไม่มีสินค้าอะไรเลย** — ร้านที่ไม่ได้ขายอะไร |
| ใช้ที่ | Verse 2, Chorus 2 |

### ลุค 4 · OVERWRITTEN (ถูกเขียนทับ)
| | |
|---|---|
| ชุด | เดรสสั้นสีชมพูพาสเทลสดจัด มีระบายเป็นชั้น · โบว์ใหญ่ที่คอ · ถุงเท้าลูกไม้ · รองเท้าส้นตึกสีขาว |
| หน้า | **แต่งหนาแบบตุ๊กตา** — บลัชวงกลมสองข้าง ตาโตเกินจริง ริมฝีปากเล็ก |
| สี | ชมพู/ขาว/ทอง อิ่มจนเกินจริง |
| หมายเหตุ | นี่คือลุค `so cute` ในเพลง — **มันควรดูน่าอึดอัดมากกว่าน่ารัก** ดวงตายังว่างเปล่าเหมือนเดิมทั้งที่หน้าถูกแต่งจัด |
| ใช้ที่ | Final Chorus (ท่อน `so cute, so blank`) |

### ลุค 5 · AWAKE (มีชื่อแล้ว)
| | |
|---|---|
| ชุด | เสื้อไหมพรมลุค 1 **แต่สีอิ่มขึ้น** เห็นเส้นถักชัด มีขุยผ้าจริง |
| หน้า | หน้าสดเหมือนเดิม แต่**มีเหงื่อบางๆ ริมจมูก มีรอยแดงที่แก้ม** — พื้นผิวคนจริง |
| ของประกอบ | **ป้ายชื่อมีตัวอักษรแล้ว** (เบลอ อ่านไม่ออก — คนดูรู้แค่ว่ามีชื่อ) |
| เฟรมเรต | **เปลี่ยนเป็นลื่น 24fps ครั้งแรกและครั้งเดียว** |
| ใช้ที่ | Bridge เท่านั้น |

> **ลุค 5 ต้องโผล่แค่ครั้งเดียวในเพลง** ถ้าใช้ซ้ำจะหมดพลัง

# 👤 ตัวละคร 2 — PLAYER (ชาย)

## Face lock

ชายเอเชียตะวันออก ต้น 20 · ตัวผอมบาง ไม่ล่ำ · ผมดำรุงรังปรกหน้าผาก · **ตาโรยเหมือนอดนอน มีขอบตาคล้ำ** · สีหน้าเบื่อ ไม่ยิ้ม · เห็นพื้นผิวผิวจริง สิวเล็กๆ ได้

> **สำคัญ: อย่าออกแบบให้หล่อ** เขาต้องดูเหมือนคนที่นั่งเล่นเกมมาหกชั่วโมง ไม่ใช่พระเอก — ตรงกับน้ำเสียงเนือยๆ ในเพลง

## Costume Sheet — 2 ลุค

### ลุค A · PLAYER (หลัก)
| | |
|---|---|
| ชุด | ฮู้ดดี้สีเทาเข้มตัวหลวม ยับ · กางเกงวอร์มดำ · ถุงเท้าขาวหมอง **ไม่ใส่รองเท้า** |
| ของประกอบ | **หูฟังคล้องคอ** (ไม่ครอบหู) · จอยเกมถือมือเดียวหลวมๆ · แก้วน้ำเปล่า |
| หมายเหตุ | ไม่ใส่รองเท้า = เขาอยู่ในพื้นที่ของตัวเอง ส่วนเธออยู่ในพื้นที่ที่ถูกสร้างขึ้น |
| ใช้ที่ | ทุก Verse, Pre-Chorus, tag ในฮุค |

### ลุค B · IN-GAME AVATAR
| | |
|---|---|
| ชุด | เสื้อคลุมนักผจญภัยเกินจริง ดาบพลาสติกใหญ่เทอะทะ ไฟเรืองแสงตามขอบ |
| หมายเหตุ | เวอร์ชันในเกมของเขา — **ดูเท่แบบตลก** ตัดกับตัวจริงที่ใส่ฮู้ดดี้ยับ |
| ใช้ที่ | แทรกสั้นๆ 2–3 เฟรมเป็นมุกตัดสลับ |

# 🎬 กฎการตัดต่อ (สร้างความ "ไวๆ weird อาร์ตๆ")

## กฎที่ 1 — ตัดที่ทุกเสียง `(beep!)`

**นี่คือกฎสำคัญที่สุด** เพลงมี blip หลังวลีหลักทุกครั้ง → **ทุก blip = 1 คัต**

ในท่อนฮุคจะได้คัตประมาณ **5 ครั้งใน 8 บาร์** โดยไม่ต้องคิดเอง จังหวะตัดจะเข้ากับเพลงอัตโนมัติ

## กฎที่ 2 — ท่อนซ้ำ ให้ใช้ภาพซ้ำเป๊ะ

ตอนเธอพูดวรรคเดิม ให้ใช้ **เฟรมเดียวกันเป๊ะ ก๊อปวาง 3 ครั้ง** ไม่ใช่ถ่ายใหม่ 3 เทค

คนดูจะรู้สึกผิดปกติทันที เพราะเห็นว่ามันคือคลิปเดิม — **นั่นคือความเป็น NPC**

## กฎที่ 3 — UI ซ้อนบนภาพ

| องค์ประกอบ | ใช้ตอน |
|---|---|
| กล่องข้อความเกมด้านล่างจอ | ทุกครั้งที่เธอพูด |
| `[E] to interact` ลอยข้างตัวเธอ | Verse |
| จุดสามจุด `...` กระพริบ | ก่อนเธอพูด |
| แถบโหลด | Pre-Chorus |
| `!` สีเหลืองเหนือหัว | ตอน `(next)` |

## กฎที่ 4 — สลับสัดส่วนภาพ

| สัดส่วน | ใช้กับ |
|---|---|
| 16:9 เต็มจอ | โลกของ Player |
| **4:3 มีขอบดำสองข้าง** | ช็อตของ NPC — เหมือนภาพเก่า/ระบบเก่า |
| 1:1 จตุรัส | ช็อตแทรกเร็วๆ |

การสลับกลางเพลงทำให้ภาพ "สะดุด" แบบมีเหตุผล

## กฎที่ 5 — Bridge หักกฎทั้งหมด

ทุกกฎข้างบน **ยกเลิกใน Bridge** — ช็อตเดียวยาว ไม่ตัดเลย กล้องนิ่ง ไม่มี UI ไม่มีขอบดำ ไม่มี glitch

หลังจากตัดถี่มา 40 วินาที การอยู่นิ่งจะรู้สึกเหมือนเวลาหยุด **นี่คือจุดที่คนดูจะรู้สึกอะไรบางอย่าง**

# 🎞 Shot List ตามท่อนเพลง

## Intro — NPC ค้างลูป
- CU หน้าเธอ ลุค 1 กล้องล็อคนิ่ง **4:3 มีขอบดำ**
- เธอกระพริบตา → **ก๊อปเฟรมเดิมวาง 3 ครั้ง** กระพริบเป๊ะเหมือนกันทุกครั้ง
- ตัดที่ `(beep!)`: ECU ป้ายชื่อเปล่าที่อก
- แทรก 2 เฟรม: หน้าจอดำมีเคอร์เซอร์กระพริบ

## Verse 1 — Player เบื่อ
- OTS จากหลัง Player (ลุค A) มองเธอผ่านจอ **16:9 handheld**
- ทุกครั้งที่เสียงหุ่นพูด → **whip pan ไปที่หน้าเธอ** แล้วสะบัดกลับ
- ช็อตมือเขากดปุ่มซ้ำๆ ที่ปุ่มเดียว
- ตอน `Right. Right. Right.` → คัต 3 ครั้ง มุมเดิม แต่**หน้าเขาเบื่อขึ้นทีละขั้น**

## Pre-Chorus — โหลด
- ECU ตาเธอ ไม่กระพริบเลย 4 วินาที
- แถบโหลดวิ่งขึ้นทับภาพ
- ตอน `Three. Two. One—` → คัต 3 ช็อต ตัวเลขซ้อนจอ **จอสั่นแรงขึ้นทุกครั้ง**

## Chorus — คัตถี่สุด
- **ตัดทุก `(beep!)` = 5 คัตใน 8 บาร์**
- สลับ: หน้าเธอลุค 1 (4:3) ↔ หน้าเขาเนือย (16:9) ↔ ECU ปาก ↔ ECU มือ ↔ wide ทั้งคู่คนละฝั่งจอ
- ทุกครั้งที่วลีหลักดัง → **แฟลชขาว 1 เฟรม**
- ช็อตทั้งคู่ในเฟรมเดียว: เขาอยู่ซ้าย (มีเงา) เธออยู่ขวา (ไม่มีเงา) — **ให้เห็นชัดว่าเธอไม่มีเงา**

## Post-Chorus — เต้น + glitch
- เธอลุค 2 (glitch) ขยับซ้ำท่าเดิมเป็นลูป 8 บาร์
- ภาพ datamosh ละลายตอน `(beep beep beep)`
- แทรก Player ลุค B (avatar ในเกม) 3 เฟรม เป็นมุก
- **สลับ 1:1 จตุรัสท่อนนี้ทั้งท่อน**

## Verse 2 — หลังเคาน์เตอร์
- เธอลุค 3 ยืนหลังเคาน์เตอร์เปล่า ป้าย OPEN กระพริบ
- เขาเอานิ้วจิ้มไหล่เธอ → **เธอไม่ขยับเลย** กล้องล็อคนิ่ง 3 วินาที
- จิ้มครั้งที่สอง → ใช้**เฟรมเดิมเป๊ะ**กับครั้งแรก
- ตอน `Locked.` → ภาพค้าง freeze 3 ครั้งสั้นๆ

## Chorus 2 — เหมือนรอบแรกแต่เพิ่มความรั่ว
- โครงเดิม แต่ป้าย OPEN เริ่มกระพริบผิดจังหวะ
- ขอบร่างเธอเริ่มแตกพิกเซลในบางคัต
- เพิ่มช็อต: เขาเริ่ม**หยุดกดปุ่ม** มองเธอนานขึ้น

## Bridge — หักทุกกฎ ⭐
- **ช็อตเดียว ยาวทั้งท่อน ไม่ตัดเลย**
- เธอลุค 5 (Awake) — **เฟรมเรตเปลี่ยนเป็นลื่นครั้งแรก**
- กล้องนิ่ง MCU หน้าเธอ ไม่มี UI ไม่มีขอบดำ ไม่มี glitch เต็มจอ 16:9
- แสงเปลี่ยนจากแบนเป็นมีทิศทาง — เห็นเงาที่แก้มเป็นครั้งแรก
- **ป้ายชื่อมีตัวอักษรแล้ว** (เบลอ)
- ท้ายท่อนตอน `(giggle) nope.` → เธอ**ยิ้มจริงครั้งเดียวในเพลง** แล้วภาพตัดดำทันที

## Final Chorus — ระเบิด
- กลับมาตัดถี่ แต่**เร็วกว่ารอบก่อน 2 เท่า**
- ตอน `so cute, so blank` → เธอลุค 4 (Overwritten) หน้าแต่งจัดแต่ตาว่างเปล่า
- สลับลุค 1/2/3/4 **คัตละลุค** ตามจังหวะ blip
- ตอน `Come close, get lost` → ซูมเข้าหน้าเธอเร็ว แล้ว**ตัดไปหน้าเขา**ที่กำลังเอื้อมมือ
- คัตสุดท้ายของฮุค: ทั้งคู่ในเฟรม **มือเกือบแตะกัน**

## Outro — กลับเป็นลูป
- เธอกลับเป็นลุค 1 กล้องล็อคนิ่ง **4:3 ขอบดำกลับมา**
- กระพริบตา — **เฟรมเดิมจาก Intro เป๊ะ**
- ป้ายชื่อกลับมาเปล่า
- จอดับ เคอร์เซอร์กระพริบ 2 ครั้ง → ดำ

> **Outro ต้องใช้ฟุตเทจเดียวกับ Intro ตรงๆ** — วนกลับที่เดิม คนดูจะรู้สึกว่าทุกอย่างถูกรีเซ็ต

# ⚠️ สิ่งที่ต้องระวังตอนเจน

- **หน้าต้องล็อกทุกช็อต** — ใช้ `<<<image_1>>>` เป็น face lock ทุกครั้ง
- **ห้ามแต่งหน้าเธอในลุค 1, 2, 3, 5** — ความสดคือตัวละคร มีแต่ลุค 4 ที่แต่งหนา
- **ห้ามทำ Player ให้หล่อ** — ต้องดูโรยและเบื่อ
- **ป้ายชื่อ** — เปล่าในลุค 1–4, มีตัวอักษรเบลอในลุค 5 เท่านั้น
- **เงา** — เธอไม่มีเงาในลุค 1–4, มีเงาในลุค 5 เท่านั้น (จุดสังเกตที่คนดูจะจับได้ทีหลัง)
- **ลุค 5 กับ Bridge ใช้ครั้งเดียว** ห้ามซ้ำ
